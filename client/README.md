# Game Collection Client

This client is built with Vite and React.

## Requirements
- Node.js LTS

## Install
```bash
npm install
```

## Run (dev)
```bash
npm run dev
```

The app runs at http://localhost:5173.

## Build
```bash
npm run build
```

## Preview the build
```bash
npm run preview
```

## Notes
- The dev server proxies API calls to the Node server on http://localhost:5000 via vite config.
